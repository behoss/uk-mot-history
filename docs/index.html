The MOT History API client for Python and TypeScript

Look up every MOT test, mileage reading, defect and recall flag for any UK vehicle by registration or VIN, straight from the official DVSA MOT History API. OAuth handled, tokens cached, retries built in, and a clocking warning wherever the mileage went down.

Everything the raw API makes you build yourself

The DVSA API needs an Entra ID token and an API key on every call, rate-limits hard and returns strings for numbers. This package deals with all of it so you can ship the feature.

OAuth2 done for you

Client-credentials token fetched once, cached for its 60 minutes, refreshed on 401. Concurrent JavaScript calls share one token request.

Retries that respect limits

429 and 5xx retried with Retry-After and exponential backoff. Typed errors for not found, invalid, auth and rate limits.

Clocking warnings

Odometer readings in miles (kilometres converted), average miles a year, and a flag wherever the mileage went down between tests.

Typed models

Frozen dataclasses for vehicle, test and defect in Python; full .d.ts types in TypeScript. Dates parsed, strings cleaned.

Runs everywhere

Python standard library only. JavaScript is one fetch-based file for Node 20+, Cloudflare Workers, Deno and Bun.

A handy CLI

uk-mot-history AB12CDE prints a readable history: results, mileage, advisories and failures, MOT expiry and recall status.

Quick start

Install from GitHub, set four environment variables from your DVSA email, and look up a car.

Python 
uv add git+https://github.com/behoss/uk-mot-history

from uk_mot_history import MotHistoryClient, find_mileage_anomalies

client = MotHistoryClient.from_env()       # MOT_HISTORY_* variables
car = client.by_registration("AB12 CDE")   # or client.by_vin(...)

print(car.make, car.model, "MOT expires", car.mot_expiry)
for test in car.mot_tests:                 # newest first
    print(test.completed_date.date(), test.test_result, test.odometer_miles)
for warning in find_mileage_anomalies(car):
    print("Clocking warning:", warning)
TypeScript / JavaScript 
// copy js/src/index.js + index.d.ts into ./mot/
import { MotHistoryClient, findMileageAnomalies, motExpiry } from "./mot/index.js";

const client = MotHistoryClient.fromEnv(env); // Workers env or process.env
const car = await client.byRegistration("AB12CDE");

console.log(car.make, car.model, "MOT expires", motExpiry(car));
for (const a of findMileageAnomalies(car)) {
  console.log(`Mileage fell ${a.drop} miles by ${a.later.date}`);
}

Get a DVSA MOT History API key

The API is free. DVSA issues keys to organisations, businesses and individuals.

  1. Read DVSA's MOT History API registration page, then fill in the registration form (name, email, postal address).
  2. Review takes up to five working days. DVSA emails a client ID, client secret, API key and the tenant ID for the token URL.
  3. Put them in environment variables, never in code. Keys from the old, pre-OAuth MOT History API don't work: register again.

API notes and gotchas

What the DVSA documentation leaves you to find out the hard way.

  • Two credentials on every call: a bearer token (client credentials, scope https://tapi.dvsa.gov.uk/.default) and the X-API-Key header. Missing either gives 401 or 403.
  • Rate limits: 500,000 requests a day, 15 a second on average, bursts of 10. Go over the daily quota and the key is blocked for 24 hours, so cache results on your side.
  • Two response shapes: a car with tests has motTests; a car too new for its first MOT has none and a motTestDueDate instead. mot_expiry and motExpiry() handle both.
  • Odometer values are strings with a unit (MI or KM) and a result type (READ, UNREADABLE, NO_ODOMETER). Use the miles helpers rather than the raw value.
  • Defect types: ADVISORY, MINOR, MAJOR, DANGEROUS, plus FAIL, PRS and USER ENTERED on older records. Same-day retests appear as separate tests.
  • Mileage drops are the classic clocking sign; a tester's typo or a replaced instrument cluster can cause them too, so treat them as a flag to investigate.
  • Bulk data: bulk_download() returns short-lived links to the full extract and daily deltas. Download them straight away.
  • Licence: the data is under the Open Government Licence v3.0. Show "Contains public sector information licensed under the Open Government Licence v3.0." wherever you display it.
